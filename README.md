- 🗄️ Django + PostgreSQL with schema-per-tenant isolation, role and field-level permissions, Celery/Redis background jobs.
- 🔗 Facebook Lead Ads and WhatsApp Cloud API integrations, with automatic lead assignment.

☁️ **QIO Cloud**: multi-tenant ERP SaaS on ERPNext.
- 💳 Built the SaaS layer: plans, Stripe subscriptions, and tenants.
